## SF64-Skeleton-Importer
* **Blender 3.6**

An add-on/extension for Fast64 (HM64) that imports Limb* Skeletons from StarFox64.

<img width="579" height="275" alt="image" src="https://github.com/user-attachments/assets/61d60626-20fe-4e1d-be31-916946b61ee7" />

> Requires [Fast64 (HM64)](https://github.com/HarbourMasters/fast64) to import with meshes.

## Usage

1. **Fast64 Panel**
   - Set the microcode as `F3DEX/LX` or higher.
   - Set the Game as `OOT` or higher.

2. **OOT Panel**
   - Set the game's **Decomp Path** `(C:\"folder")`
   - Set the **Game Version** to `Legacy`
   - Set the **Feature Set** to `HM64`

3. **Import**
   - In the **C file** field, select the `.c` file that contains your Limb skeleton.
   - In the **Name** field, enter the name of your skeleton.
   - Click **Import**.

4. **Choose the import mode**
   - **Import Skeleton Only** — imports just the skeleton
   - **Import All (Fast64)** — imports everything *(requires the Fast64 HM64 addon to function)*
