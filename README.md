# SF64-Skeleton-Importer
An add-on/extension for Fast64 (HM64)


Imports Limb* Skeletons from StarFox64



<img width="579" height="275" alt="image" src="https://github.com/user-attachments/assets/61d60626-20fe-4e1d-be31-916946b61ee7" />




Requires Fast64 (HM64) to import with meshes.
https://github.com/HarbourMasters/fast64

# Usage
**-Set the microcode in Fast64 as F3DEX/LX or higher.**

**-In the C file field, select the .c file that contains your Limb skeleton.**

**-In the Name field, enter the name of your skeleton.**

**-Click Import** 

**-Import Skeleton Only**

**or**

**-Import All (Fast64)** //Requires Fast64 (HM64) Addon to function
